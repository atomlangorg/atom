# Atom

## About

Atom is a programming language focused on having a great type system, consistent syntax, and being easy to use.

Atom focuses on being a modern alternative to other general purpose programming languages. The language's design is strongly inspired by [Swift](https://www.swift.org) and [Rust](https://rust-lang.org).

The compiler is written in [Rust](https://rust-lang.org) and generates native machine code with [LLVM](https://llvm.org).

> [!CAUTION]
> This project is in early development and is unstable. It is not currently suitable for production use.
